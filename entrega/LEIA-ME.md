# Entrega - Simulado SAEP

Esta pasta contém os arquivos exigidos pelo enunciado: `documentacao.pdf`, `DER.png`, `saep_db.sql`, `casos_de_teste.pdf`, `infraestrutura.pdf` e `sistema/`. A pasta `banco/` contém os SQLs separados para criar, popular, conferir e atualizar o esquema com perfis.

Antes de entregar, substitua `NOME_DO_ALUNO` no nome da pasta compactada pelo seu nome. Para executar no IntelliJ, abra esta pasta como projeto Gradle, selecione o JDK 11 para o Gradle e use a configuração **SAEP - Site**. Inicie o MySQL antes. Leia `sistema/README.md` para mais detalhes e abra o site em `http://127.0.0.1:8080`.

O código Java compila. O DER foi reconstruído a partir do esquema importado no banco e inclui a tabela `perfis`. A aba **Meu perfil** permite editar dados, função exibida, bio, foto, banner e senha. Inicie o banco pelo XAMPP antes de abrir o site.
