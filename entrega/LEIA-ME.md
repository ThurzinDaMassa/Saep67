# Entrega - Simulado SAEP

Esta pasta contém os arquivos exigidos pelo enunciado: `documentacao.pdf`, `DER.png`, `saep_db.sql`, `casos_de_teste.pdf`, `infraestrutura.pdf` e `sistema/`. A pasta `banco/` contém os SQLs separados para criar, popular e conferir o esquema.

Antes de entregar, substitua `NOME_DO_ALUNO` no nome da pasta compactada pelo seu nome. Leia `sistema/README.md` para abrir o site local em `http://127.0.0.1:8080`.

O código Java compila. Passaram 14 verificações de lógica, 19 de integração com a instância MariaDB 10.4.32 do XAMPP, 12 dos componentes Swing e 38 verificações HTTP do site. O DER foi reconstruído a partir do esquema importado no banco. Inicie o banco pelo XAMPP antes de abrir o site.
