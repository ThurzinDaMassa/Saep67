# Prompt aprimorado para a interface do sistema SAEP

Redesenhe a interface web do sistema de gestão de estoque de ferramentas do simulado SAEP, mantendo todas as funcionalidades existentes em Java e MySQL.

Crie uma experiência visual profissional, moderna e sóbria, adequada a um painel administrativo de almoxarifado. Use uma paleta consistente em azul petróleo, verde discreto, branco e cinzas neutros; tipografia legível; espaçamento bem planejado; títulos e dados com hierarquia clara. Use superfícies planas, bordas finas e cantos retos, sem arredondamento. Evite cartões repetitivos, sombras decorativas, emojis e elementos sem função.

Organize a versão para computador com navegação lateral, barra superior, indicadores objetivos e tabelas fáceis de consultar. Na tela de entrada, apresente a identidade do sistema e um formulário de acesso claro. Use ícones SVG vetoriais com o mesmo estilo visual e significado inequívoco para produtos, estoque, histórico, alertas, pesquisa, edição e exclusão.

Garanta responsividade para celular, estados de foco visíveis, contraste adequado, rótulos nos formulários, mensagens de sucesso e erro legíveis e navegação por teclado. Preserve cadastro e edição de produtos, entradas e saídas de estoque, alertas de mínimo, histórico, autenticação e integração com MySQL. Entregue o código pronto para executar, sem depender de serviços externos para os ícones ou estilos.
